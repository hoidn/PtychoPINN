# Generator gridsize>1 (object_big) Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to execute this plan task-by-task (fresh implementer per task, task review, final whole-branch review). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enable physically principled gridsize>1 training for generator-type models (hybrid_resnet first), equivalent to the built-in CNN's `object_big` path, validated end-to-end on the grid-lines pipeline.

**Architecture:** Reuse the existing architecture-agnostic `object_big` physics branch in `PtychoPINN.forward` (merge the C=gridsize² predicted patches into one shared bigN×bigN object via `reassemble_patches_position_real`, re-extract per-position patches via `extract_channels_from_region`, apply probe + diffraction loss per position). All changes live in runner wiring, generator modules, reassembly, and tests. `ptycho_torch/model.py` is **not** modified — if that turns out to be impossible, the plan is wrong and execution stops.

**Tech Stack:** PyTorch/Lightning (`ptycho_torch/`), pytest (`tests/torch/`), grid-lines simulation workflow, aligned-recipe conventions from `scripts/studies/aligned_hybres_ablation_driver.sh`.

### Task 3c: Fix gridsize>1 torch inference reconstruction routing (inserted 2026-07-06 after Step 7 gate failure + RCA)

**Why (RCA evidence, `.superpowers/sdd/ext/task-gs2-t3c-rca-report.md`):** The runner's default `reassembly_mode="grid_lines"` sends `forward_predict`'s channels-first per-patch output `(B, C=4, 128, 128)` to `ptycho.workflows.grid_lines_workflow.stitch_predictions`, whose gs>1 regrid guard tests `processed.shape[-1] == gridsize**2` (`grid_lines_workflow.py:846`) — `128 ≠ 4`, so the guard silently skips and B·C=2916 heavily-overlapping patches are flat-tiled on a 54×54 grid, then aliased by `_harmonize_prediction_shape` into the observed weave. This TF grid-tiling stitch assumes non-overlapping channels-last tiles; neither holds for torch object_big gs>1 output. Correct at gs1 (C=1) — every gs1 baseline pins this path. The `position` path (`_reassemble_with_coords_offsets`: coords_offsets + shift_and_sum) reconstructs the same patches coherently in both BHWC and BCHW layouts (RCA Probe 2).
