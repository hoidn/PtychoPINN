# PtychoPINN Test Suite Index

This document provides a comprehensive index of the automated tests in the `tests/` directory. Its purpose is to make the test suite discoverable, explain the scope of each test module, and provide direct commands for running specific tests.

## How to Run Tests

Pytest is the project standard:

- **Run all tests:** `pytest tests/ -q`
- **Run a specific file:** `pytest tests/image/test_cropping.py`
- **Run a specific test class/method:** `pytest tests/test_integration_workflow.py::TestFullWorkflow`

Legacy unittest modules (genuine `unittest.TestCase` subclasses) may still be run via `python -m unittest <dotted.module>`; see the Usage/Command column below for the exact form per module.
